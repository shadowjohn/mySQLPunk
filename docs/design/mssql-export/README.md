# MSSQL SQL 匯出精靈：互動畫面原型

這是 2026-10-12 設計討論用的獨立 HTML 原型，尚未接入 WinForms 或匯出引擎。所有資料、速度、ETA、檢查結果、成功與取消狀態均為模擬；不連線資料庫，也不產生 SQL 檔案。

使用者已於 2026-10-12 同意此畫面及修訂後的正式功能規格：[design.md](design.md)。[實作計畫](implementation-plan.md) 已整理，待審閱與選擇執行方式；正式匯出程式尚未實作。

## 開啟

可直接開啟 `index.html`，或以 Python 3.8+ 啟動本機預覽：

```powershell
python docs/design/mssql-export/serve-preview.py --port 17643
```

網址：`http://127.0.0.1:17643/docs/design/mssql-export/index.html`

預覽伺服器只綁定 loopback，僅提供此頁與三個明確允許的 Punky 素材，不提供資料夾索引。按 Ctrl+C 停止。

## 可以操作

- 上方原型導覽直接切換選表、輸出設定、確認、進度與完成。
- 選表預設全選；可搜尋表名／註解，跨搜尋保留勾選，零選取停用下一步。
- 選擇結構與資料／僅結構／僅資料；編輯示意輸出路徑。
- 右下情境選單可模擬未啟用快照，查看確認頁的提示與停用開始按鈕。
- 從確認頁按「開始模擬匯出」，約 40 秒內走過資料匯出、檔案驗證與完成；取消則經過停止與清理的模擬狀態。
- 深淺色切換；進度頁 Punky 自動循環播放，只有靜音控制。實際開始模擬時嘗試播放一次原音；仍受瀏覽器播放政策與裝置音量影響。
- 開啟資料夾是示意動作，會提示沒有實際輸出。

## 素材與邊界

直接引用既有 `mySQLPunk/image/punky_report_loading_atlas.png`（384px、73 格、83ms／格）、靜態圖與 WAV，不複製大型素材。正式版仍需以真正的 MSSQL 工作狀態、吞吐量與檔案驗證結果驅動畫面；本原型的數字與進度算法不可當成實作。

原型導覽是設計檢視工具，正式精靈執行中不能藉此切換設定。正式 Windows 儲存檔案對話框、真實連線／SSH、快照條件、取消 SQL、串流匯出與還原驗證均未實作。
