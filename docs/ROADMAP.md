# 功能路線圖(對照 Navicat)

使用者希望把 Navicat 17 亮點與 Navicat Premium 的功能面逐步補進 mySQLPunk。
這份文件是對照表:哪些已經有了、哪些剛做完、哪些排在後面、哪些明確不做(附原因)。
每輪動工前先看這份,做完就更新狀態。

狀態標記:✅ 已有|🆕 本輪新增|📋 排程中|❌ 不做

## Navicat 17 亮點對照

| Navicat 功能 | 狀態 | 說明 |
| --- | --- | --- |
| AI 助理(聊天面板) | 🆕 | 右側停靠面板,OpenAI 相容 API(GitHub Models/OpenAI/Ollama/自訂),金鑰存 Windows 認證管理員 |
| 詢問 AI(SQL 助理) | 🆕 | 同上面板:可附資料庫結構上下文,回覆的 SQL 一鍵插入查詢分頁 |
| 修正 SQL 錯誤 | 🆕 | 走 AI 面板的建議提問;之後可加「編輯器內一鍵送修」 |
| 資料建模(多模型工作區/圖表設計/模型同步) | 📋 | 大型工程,規劃獨立的 ER 檢視先行(唯讀顯示外鍵關聯) |
| 資料字典 | 🆕 | 資料庫節點右鍵「產生資料字典」,輸出 HTML(瀏覽器可另存 PDF) |
| 資料分析(欄位統計/分佈) | 📋 | 規劃:資料表右鍵「資料分析」,統計 NULL/相異值/極值/Top 值 |
| 查詢見解(視覺化執行計劃) | 📋 | 規劃:EXPLAIN 結果的樹狀/表格檢視(MySQL/PG JSON 計劃先做) |
| 釘選查詢結果 | 🆕 | 查詢視窗 📌 按鈕,快照分頁可比較,中鍵關閉 |
| 資料表設定檔(篩選/排序/欄顯示組合) | 📋 | 既有「記住資料表設定」再擴充成多組具名設定 |
| URI 分享物件 | 📋 | mysqlpunk:// 協定已註冊,補「複製物件 URI」與啟動定位 |
| 進階搜尋 | 🆕 | 連線清單上方搜尋框,名稱/群組即時篩選 |
| 多連線集中管理 | ✅ | 連線清單 + 多層群組 + 拖曳分組 |
| 專注模式 | 🆕 | F11 或檢視選單,一鍵隱藏工具列/導覽/資訊窗格 |
| BI 儀表板互連/自訂運算式 | ❌ | BI 屬另一個產品等級的工程,現有 BI 入口維持基本功能 |
| MongoDB / Snowflake / Redis / Garnet | ❌ | 新增資料庫引擎的成本極高,聚焦既有五種引擎的完成度 |
| Linux ARM | ❌ | WinForms 限定 Windows |

## Navicat Premium 功能頁對照

| Navicat 功能 | 狀態 | 說明 |
| --- | --- | --- |
| 主要視窗(樹狀導覽/物件清單/分頁) | ✅ | |
| 物件設計器(Table Designer) | ✅ | 建表 + 多引擎 ALTER;進階 constraint 持續補強 |
| 資料檢視與編輯(網格) | ✅ | 分頁瀏覽、編輯寫回、無主鍵警告 |
| 自動完成程式碼 | ✅(基本) | 關鍵字+資料表名稱前綴;📋 欄位補全、上下文感知 |
| 程式碼片段(Snippets) | 📋 | 規劃:查詢視窗片段選單 + 自訂片段 |
| 視覺化解釋(Explain) | 📋 | 同上面「查詢見解」 |
| 匯入/匯出精靈 | ✅(MySQL 完整) | 其他引擎單表 dump/簡易匯入;📋 對等化 |
| 資料產生 | ✅ | 資料表節點可產生 INSERT 測試資料 |
| 資料同步/結構同步 | 📋 | 大型工程:先做「兩庫結構差異比對報告」再談同步執行 |
| 備份/還原 | ✅ | 邏輯 SQL 備份 + 隔離還原 + 完整性排程 |
| 自動執行(排程) | 📋 | 規劃:Windows 工作排程器整合(備份/查詢匯出) |
| 使用者與權限管理 | ✅(MySQL/MariaDB) | 📋 PG role / SQL Server login / Oracle user |
| 雲端/協同(Navicat Cloud) | ❌ | 無伺服器端;以連線匯出檔 + git 版控替代 |
| SSH/HTTP 通道 | 📋 | 連線安全最優先的缺口,含 SSL 選項 UI |

## 下一輪建議順序

1. 資料分析(欄位統計)——使用者體感強、風險低
2. 視覺化執行計劃(MySQL/PG)
3. 程式碼片段 + 欄位自動完成
4. 資料表設定檔(多組具名)
5. SSH tunnel + SSL 選項 UI(工程較大,單獨一輪)
